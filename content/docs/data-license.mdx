## Two separate licenses

Country State City uses separate licenses for software and data:

| Layer                       | License                                                                 | Applies to                                                 |
| --------------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------- |
| Source code                 | [MIT](https://github.com/tansuasici/CountryStateCity/blob/main/LICENSE) | Application, package, MCP server, and build tooling        |
| Country/state/city database | [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)              | Canonical JSON, compact/sharded data, and database exports |

## Data source

The database is derived from [Countries States Cities Database](https://github.com/dr5hn/countries-states-cities-database), which is published under ODbL 1.0 with attribution required.

The historical import recorded by this repository on August 10, 2025 did not preserve an exact upstream revision. We do not invent one. Current corrections are checked against the pinned comparison baseline [`0fc88a6`](https://github.com/dr5hn/countries-states-cities-database/commit/0fc88a640175d0950512a370e35a61d14936d0d0), verified on August 5, 2026. Full machine-readable details are available in [`data/provenance.json`](https://github.com/tansuasici/CountryStateCity/blob/main/data/provenance.json).
