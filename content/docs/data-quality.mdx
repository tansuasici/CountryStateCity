## Release automation

```bash
npm run data:quality-dashboard
npm run test:quality-dashboard
```

The generator exits with an error when the release gate has an unresolved critical/high finding or when a protected record-count baseline drifts without review. The same check runs before package publishing and website builds.

The public view includes only release evidence and reviewed exceptions. Contributor-abuse signals, credentials, and private maintainer queues remain outside the published artifact.
